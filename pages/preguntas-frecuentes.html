Preguntas frecuentes

Respuestas rápidas antes de cotizar.

Estas respuestas reflejan el estado actual de la aplicación estática y local.

¿La calculadora es gratuita?

La versión pública actual se puede usar sin pago, sin cuenta y sin backend.

¿Dónde se guardan mis datos?

Se guardan en LocalStorage del navegador del dispositivo que estás usando.

¿Puedo usarla sin conexión?

Si la página ya cargó en tu navegador, varias funciones pueden seguir disponibles localmente. La detección automática de moneda requiere conexión si se usa.

¿Qué ocurre si borro los datos del navegador?

Puedes perder trabajos, clientes, cotizaciones, impresoras, bobinas, reportes configurados y preferencias guardadas localmente.

¿Cómo traslado mis datos a otro computador?

Exporta un respaldo JSON o los datos del módulo correspondiente e impórtalos en el otro navegador.

¿El precio calculado es obligatorio?

No. Es una estimación para ayudarte a decidir. Puedes ajustar el precio según condiciones reales, mercado y criterio comercial.

¿Puedo utilizar diferentes monedas?

Sí. La moneda cambia el formato y se guarda en datos históricos cuando corresponde. La aplicación no convierte automáticamente valores entre monedas.

¿Cómo se calcula el costo por gramo?

Puedes ingresarlo directamente o ingresar precio por kilo; en ese caso la calculadora divide el precio del kilo por 1000.

¿Puedo registrar varias impresoras?

Sí. El módulo de impresoras permite guardar perfiles reutilizables para costos y características.

¿Puedo controlar bobinas?

Sí. El inventario de filamentos permite registrar bobinas, stock disponible, costo por gramo y movimientos de consumo.

¿La aplicación reemplaza la contabilidad?

No. Los reportes son de gestión y no reemplazan contabilidad, declaraciones oficiales ni asesoría profesional.

¿Puedo instalarla como aplicación?

Actualmente funciona como sitio web estático. Puede agregarse como acceso directo desde el navegador, pero no se implementó una instalación PWA completa en esta fase.
