Privacidad

Datos locales y uso real de servicios externos.

Esta página describe el comportamiento actual de la aplicación estática.

Datos guardados localmente

La aplicación guarda información en LocalStorage del navegador. Puede incluir configuración, último cálculo, trabajos, clientes, cotizaciones, datos del negocio, preferencias de navegación, impresoras, bobinas, movimientos de inventario, reportes y respaldos recientes.

Esos datos quedan asociados al navegador y dispositivo donde se usan. Si cambias de navegador o computador, no aparecerán automáticamente.

Exportar, importar y eliminar

La aplicación incluye exportaciones JSON, CSV y respaldo completo para trasladar o conservar información. También existen acciones para borrar datos en módulos específicos.

Si limpias los datos del navegador, usas modo incógnito o el navegador elimina almacenamiento local, puedes perder la información guardada si no tienes un respaldo.

Servicios externos identificados

La calculadora puede solicitar una detección aproximada de país para sugerir moneda. Para eso intenta consultar https://ipapi.co/json/ y, si falla, https://api.country.is/.

Estos servicios pueden recibir la dirección IP como parte normal de cualquier conexión web. La aplicación guarda localmente el país y moneda sugeridos durante un período limitado para no consultar en cada carga.

La calculadora no solicita GPS, cámara ni micrófono.

Cookies, analítica y anuncios

En el estado actual no se agregó analítica, publicidad ni cookies propias para seguimiento. Si se agregan esos servicios en el futuro, esta página debe actualizarse antes de publicarlos.

Sin cuentas ni servidor propio

La versión actual no tiene login, usuarios, base de datos externa ni backend propio para guardar tus trabajos.

Este texto es informativo y debe revisarse si el proyecto incorpora cuentas, pagos, analítica, anuncios, backend o servicios externos adicionales.
